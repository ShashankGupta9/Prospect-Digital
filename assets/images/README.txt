Prospect Digital — general images
=================================

og-default.jpg
  1200 x 630 px social share image used by Open Graph and Twitter cards on
  every page. Replace with a branded image that includes your logo and a short
  promise. Keep the file name so no code changes are needed.

Add any other shared photography or illustrations here (team photos, office
images, client logos you have permission to use) and reference them with
asset('images/your-file.webp') in a template.

Always write descriptive alt text for content images, and keep decorative
images aria-hidden.
